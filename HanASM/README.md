# HanASM (中文汇编语言与自举编译器)

这是一个完全从零开始的中文编程语言项目。目标是构建一套中文优先、中英兼容的编程体系，最终实现自举。

## 当前进度 (Phase 1 已达成)
- [x] C++ 实现的中文汇编器 (`compiler/`)
- [x] 纯 C++ 实现的中文汇编运行器（软件 CPU，无需 DOSBox）(`runner/`)
- [x] VS Code 语法高亮与一键编译插件 (`vscode-extension/`)

## 快速体验
1. 在 VS Code 插件目录下执行 `npm install` 并按 `F5` 启动插件测试。
2. 编写 `.asm` 文件，使用 `装 甲, 10` 等中文指令。
