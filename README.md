# HanASM (中文汇编语言与自举编译器)

![AI-Assisted](https://img.shields.io/badge/AI-Assisted-blueviolet)
![C++](https://img.shields.io/badge/C%2B%2B-17-blue)
![License](https://img.shields.io/badge/license-MIT-green)

这是一个**完全从零开始的中文编程语言项目**。我们的目标是构建一套中文优先、中英兼容的底层编程体系，打破语言壁垒，最终实现**完全自举**（用中文写中文编译器）。

> **核心理念**：底层脏活累活（x86机器码解析、虚拟内存管理）由 C++ 与 AI 辅助完成；上层的语法设计、应用开发与生态建设，由人类架构师与开发者主导。

## 🚀 当前进度 (Phase 1 已达成)

- [x] **C++ 中文汇编器**：将中文源码编译为 32 位 DOS COM 格式机器码。
- [x] **纯 C++ 中文运行器**：极简版“软件 CPU”，彻底摆脱 DOSBox 依赖，完美支持 UTF-8 中文输出！
- [x] **VS Code 扩展**：提供完整的中文语法高亮（支持全角标点）与一键编译。
- [ ] Phase 2：用中文汇编写出微型中文 C 语言编译器。

## 📁 目录结构

```text
HanASM/
├── 编译器/             # C++ 实现的中文汇编器 (将 .asm 转为 .com 机器码)
├── 跑者/               # C++ 自研软件 CPU (运行器，直接执行机器码并打印)
└── VScode扩展/         # VS Code 插件 (语法高亮与一键编译)


. 编译底层引擎
进入 编译器/ 目录，编译 C++ 源码：
g++ -std=c++17 *.cpp -o asm.exe
2. 编译并运行运行器
进入 跑者/ 目录，编译自研软件 CPU：
g++ -std=c++17 -O2 runner.cpp -o runner.exe
3. 编写你的第一段中文代码
新建一个 测试.asm 文件，输入以下代码：
入口
    装 丁, 问候语
    系调 9
    系调 4Ch

字串 问候语 = "你好，中文汇编！$"
4. 见证奇迹
使用 asm.exe 编译生成 测试.com，然后让自研的软件 CPU 跑起来：

bash
./runner.exe 测试.com
输出结果：

text
